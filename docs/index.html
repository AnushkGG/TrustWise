TrustWise

Trust-first research pipeline: planning, web and paper agents, trust scoring, SQLite, and insights (local Ollama or optional Gemini).

Source & CI

This static page is hosted by GitHub Pages. The full application runs Python and Node on your machine or a container host — not on Pages.

View repository GitHub Actions

Run the full UI locally

Install dependencies, start Ollama (optional), then from the repo root: cd web && npm install && npm run build && npm start — open http://localhost:5000.

Deploy the full stack online

Use the included Dockerfile on Render, Fly.io, Railway, or any container host. Set HOST=0.0.0.0 and PORT as required by the platform.
